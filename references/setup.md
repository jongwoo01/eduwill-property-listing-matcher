# 매물장 준비와 전환

## 새 매물장

요청에 저장 방식이 있으면 그대로 따른다. 없을 때만 한 번 묻는다.

> 어디에 만들까요? Google Sheets 또는 이 컴퓨터의 Excel 중 하나를 골라주세요.

### 빈 Excel 매물장

“엑셀 매물장 만들어줘”에는 저장할 **기존 폴더만** 묻는다. 기존 자료를 요구하지 않고 빈 `매물`·`매물상세` 탭을 만든다.

```bash
python3 <tool> create-excel --directory /절대경로/폴더
```

기본 파일과 프로필 이름은 `매물장.xlsx`·`매물장`이다. 충돌하면 둘 다 `매물장-2`, `매물장-3` 순서로 첫 빈
이름을 쓴다. 생성 → 두 탭과 헤더 검증 → 프로필 저장·활성화 순서이며, 실패하면 이전 활성 프로필을 유지한다.

### 빈 Google 매물장

`google-sheets-workflow.md`의 연결 게이트를 먼저 통과한다. 표준 `.xlsx`를 네이티브 Google Sheets로 가져오고 새 ID,
두 탭과 헤더를 검증한 뒤에만 새 프로필을 활성화한다. 기존 시트와 프로필은 남긴다.

## 기존 자료 연결·이관

- 표준 Google 시트 링크: 계정·ID·탭·헤더를 확인하고 연결한다. 기본 프로필 이름은 실제 스프레드시트 제목이다.
- 표준 Excel 파일: 절대경로·두 탭·헤더를 확인하고 연결한다. 기본 프로필 이름은 확장자를 뺀 파일명이다.
- 이름이 이미 있으면 `-2`, `-3` 순으로 고유하게 정한다. 사용자가 다른 이름을 원할 때만 이름을 묻는다.
- CSV·PDF·채팅 자료: `import-workflow.md`에 따라 원본은 수정하지 않고 사용자가 고른 운영 원본으로 옮긴다.

확인된 값만 기록한다. 모르는 값은 `?`, 해당 없는 가격은 빈칸이며 핵심값이 빠지면 `상태=보류`다.

## 전환

```bash
python3 <tool> profile list
python3 <tool> profile activate --name <기존이름>
```

전환은 삭제가 아니다. 새 연결은 새 이름으로 저장한다. 같은 이름의 `--replace`는 사용자가 덮어쓰기를 명시한 경우에만 쓴다.

## 완료·오류 안내

성공 시 운영 원본 링크 또는 절대 파일 경로, 처리·보류 건수, 다음 검색 예시 하나를 준다. 실패 시에는 실패한 단계,
기존 원본이 바뀌지 않았다는 사실, 사용자가 할 다음 행동 하나를 말한다.
