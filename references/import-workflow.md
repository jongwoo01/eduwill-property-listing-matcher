# 비표준 자료 이관

CSV·기존 Excel·PDF·채팅의 매물 정보를 표준 Google Sheets 또는 Excel 운영 원본으로 옮길 때만 읽는다. 출발 자료는
읽기 전용으로 두고, 먼저 사용자가 고른 저장 방식과 대상 원본을 확정한다.

## 이관 순서

1. 출발 자료의 후보 건수와 필드를 확인하고 28열 `매물`, 필요한 경우 20열 `매물상세`에 대응시킨다.
2. 확인된 값만 넣는다. 모르는 값은 `?`, 해당 없는 가격은 빈칸이며 `종류·거래·지역` 중 하나라도 미확인이면 보류다.
3. 검색·계약 판단을 바꾸는 필드가 여러 뜻으로 해석될 때만 사용자에게 묻는다. 나머지는 `?`로 남기고 확인 항목으로 보고한다.
4. 한 번에 최대 1,000건씩 준비한다. Excel은 `add`, Google은 `prepare-add` 결과를 대상 범위에 쓴다.
5. 쓴 번호와 셀을 다시 읽고 출발 후보·등록·보류·중복·건너뜀 건수를 나눠 보고한다.

PDF에서 표나 문자를 추출했더라도 판독값을 사실로 단정하지 않는다. 애매한 값은 `?`로 둔다. 채팅의 여러 매물이 한 문장에
섞였으면 물건 경계를 먼저 나누며, 경계가 불명확하면 쓰기 전에 확인받는다. 오류가 나면 출발 자료가 변경되지 않았음을 알리고,
재조회로 확인한 반영 번호와 미반영 번호를 구분한다. 부분 성공 건을 새 번호로 다시 등록하지 않는다.
