# 손님용 문안

검색 결과를 손님에게 그대로 보낼 수 있는 문장으로 바꿀 때 읽는다. 사용자가 요청했을 때만 만든다.

## 목차

- 만들기 전 확인
- 담을 것과 빼는 것
- 구조
- 표현 규칙
- 예시
- 만들지 않는 경우

## 만들기 전 확인

1. 대상이 `matches`인지 확인한다. `needs_verification`은 적합 매물 수에 포함하거나 조건에 맞는 매물이라고 부르지 않는다.
   사용자가 원할 때만 문안 끝의 별도 `확인 필요 후보`로 표시한다.
2. 몇 건을 보낼지 정한다. 기본 3건이며, 사용자가 지정하면 따른다. 5건을 넘기지 않는다.
3. 손님이 말한 하드 조건을 다시 확인한다. 문안 첫 줄에서 그 조건을 되짚어야 손님이 "내 조건을 듣고 골랐구나"를 안다.

## 담을 것과 빼는 것

| 담는다 | 뺀다 |
| --- | --- |
| 매물의 핵심 조건(가격·면적·층·입주가능일 등 손님 조건에 걸린 항목) | 소유자 이름·연락처 등 `매물상세`의 개인정보 |
| 이 매물이 손님 조건에 맞는 이유 | 내부 번호, JSON 필드명, `matches`·`hard`·`soft` 같은 도구 용어 |
| 확인이 필요한 항목과 확인하겠다는 안내 | 확인되지 않은 값을 확정처럼 쓴 표현 |
| 다음 행동(연락·방문 일정) 제안 하나 | 시세 판단, 투자 권유, 세금 계산 결과 |

`?`인 값은 문안에 사실로 쓰지 않는다. 필요하면 "확인 후 안내드리겠습니다"로 남긴다.

## 구조

```
1) 조건 되짚기      "말씀하신 마포구 원룸, 보증금 1500 이하 월세 60 이하로 찾아봤습니다."
2) 후보 3건         매물마다 2~4줄. 핵심 조건 → 맞는 이유 순.
3) 확인 필요        해당 매물이 있을 때만. 무엇을 확인하는지 적는다.
4) 다음 행동 하나   "편하신 시간 알려주시면 방문 일정 잡아드리겠습니다."
```

카카오톡으로 보내는 경우가 많으므로 문단을 짧게 끊고 전체를 화면 두세 개 안에 넣는다.

## 표현 규칙

- 매물 소개 뒤에는 "현재 소개 가능 여부를 확인한 뒤 안내드리겠습니다"에 해당하는 문장을 넣는다. 매물장의 정보가 최신이라는 보장이 없기 때문이다.
- 단정하지 않는다. "가능합니다"가 아니라 "확인해 드리겠습니다"로 쓴다.
- 매물끼리 우열을 매기지 않고 조건 차이를 보여준다. 선택은 손님이 한다.
- 조건에 맞지 않아 제외한 매물을 굳이 설명하지 않는다.

## 예시

아래는 설명을 위해 만든 가상 사례다. 실제 매물장 값이 아니다.

전제 — 손님 조건: 마포구 원룸, 보증금 1500 이하, 월세 60 이하, 반려동물 필수. 검색 결과 적합 2건,
확인 필요 1건(반려 여부 `?`). 사용자가 확인 필요 후보도 함께 알려달라고 요청했다.

```
말씀하신 마포구 원룸으로 보증금 1500, 월세 60 안쪽에서 골라봤습니다.

1. 신촌동 / 보증금 1000 · 월세 55 · 관리비 5
   전용 23㎡, 4층, 즉시 입주 가능합니다. 반려동물 가능한 곳이고 신촌역 도보 5분입니다.

2. 합정동 / 보증금 1500 · 월세 58 · 관리비 4
   전용 25㎡, 3층입니다. 반려동물 가능하고 합정역 도보 7분, 9월 중순부터 입주 가능합니다.

별도로 가격과 지역은 맞지만 반려동물 가능 여부가 확인되지 않은 후보가 한 곳 있습니다.
확인되는 대로 바로 알려드리겠습니다.

세 곳 모두 현재 소개 가능한지 확인한 뒤 안내드리겠습니다.
편하신 시간 알려주시면 방문 일정 잡아드리겠습니다.
```

## 자동으로 만들지 않는 경우

- 사용자가 요청하지 않았다면 검색 결과에 긴 문안을 자동으로 붙이지 않는다. 다음 요청 예시로만 제안한다.
- `matches`가 0건인 일반 검색에는 문안을 자동 생성하지 않고, 중개사에게 `relaxations` 조건 조정안을 제시한다.
- 사용자가 손님에게 보낼 0건 안내를 명시적으로 요청하면 “현재 확인된 조건 일치 매물이 없다”는 짧은 문안과 조정 가능한
  조건 하나를 묻는 다음 행동을 만든다. 조건 조정안을 실제 매물처럼 표현하지 않는다.
- 세금·대출·규제 금액을 묻는 문안은 만들지 않는다. 세율과 규제는 자주 바뀌므로 확인 항목만 알려주고 공식 계산기로 안내한다.
