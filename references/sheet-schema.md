# 매물장 스키마

## 목차

- 검색용 매물장
- 상세 매물장
- 값 규칙
- 법정 서식과의 관계
- 규모 확장

## 검색용 매물장

`매물` 탭은 한 행에 매물 하나, 1행에 헤더 하나만 둔다. 검색과 순위에 필요한 28개 컬럼을 사용한다.

| # | 컬럼 | 형식 |
| --- | --- | --- |
| 1–4 | 번호, 상태, 종류, 거래 | 번호는 고유값, 상태는 진행/보류/완료 |
| 5–8 | 지역, 동네, 단지명, 동호 | 지역=시군구, 동네=읍면동 |
| 9–12 | 매매가(만원), 보증금(만원), 월세(만원), 관리비(만원) | 숫자 또는 `?`; 해당 없으면 빈칸 |
| 13–19 | 전용(㎡), 방수, 욕실, 층, 총층, 향, 준공 | 숫자·연도·방향 또는 `?` |
| 20–23 | 주차(대), 반려, 옵션, 입주가능 | Y/N/`?`, 숫자, 즉시/협의/날짜 |
| 24–27 | 인근역, 역도보(분), 초등학교, 초등도보(분) | 이름과 숫자를 분리 |
| 28 | 접수일 | YYYY-MM-DD 또는 `?` |

검색용 파일에는 소유자 이름·연락처를 넣지 않는다. `접수일`은 동점 정렬에 쓰므로 상세 파일이 아니라 검색용 파일에 둔다.

## 상세 매물장

`매물상세` 탭은 `번호`로 검색용 탭과 연결한다. 권리·시설·개인정보·계약 이력처럼 후보를 좁힌 뒤 확인할 정보를 둔다.

| 컬럼 | 내용 |
| --- | --- |
| 번호 | 검색용 매물 연결키 |
| 소유자, 연락처 | 개인정보 |
| 권리관계, 임대차현황 | 등기·임대차 확인 내용 |
| 용도지역, 건폐율·용적률, 위반건축물 | 공법·건축물 확인 내용 |
| 주차시설유형, 관리상세, 시설상태 | 확인·설명 보조 정보 |
| 옵션상세, 학군상세, 비선호시설 | 추가 확인 정보 |
| 공시가격, 취득조세 | 가격·조세 보조 정보 |
| 특약·메모, 접수경로 | 자유서술·출처 |
| 계약일, 실제계약금액(만원) | 완료 이력; 모르면 `?` |

## 값 규칙

- 가격은 만원 단위 숫자로 저장한다. `3억 5천`은 `35000`이다.
- 알 수 없으면 `?`, 거래유형상 해당 없으면 빈칸으로 둔다.
- `종류·거래·지역`이 불완전해도 행을 기록하되 `상태=보류`로 둔다.
- `반려`, `옵션`은 Y/N/`?`만 사용한다.
- 색상·병합셀·여러 줄 헤더로 상태를 표현하지 않는다.
- 주소·메모에 쉼표나 줄바꿈이 있어도 CSV 도구가 인용 처리하도록 직접 문자열 분할을 금지한다.
- 번호는 도구가 중복 없이 생성하며, 사용자가 임의로 재사용하지 않는다.

## 법정 서식과의 관계

이 스키마는 매칭용 축약 데이터이며 법정 중개대상물 확인·설명서를 대체하지 않는다. 2024년 개정 별지 제20호서식에는
관리비, 주차시설, 초·중·고 교육시설 소요시간 등이 포함된다. `주차(대)`·반려·방수·옵션처럼 매칭에 필요한 표현은
법정 서식의 필드와 정확히 같지 않으므로 별도로 확인한다.

법정 사항을 안내하거나 서류를 만들 때는 국가법령정보센터의 현행 서식을 다시 확인한다.

## 규모 확장

매물이 수백 건을 넘으면 전부 모델에 올리지 말고 결정적 도구가 운영 원본을 직접 검색하게 한다. 15,000건 이상에서도
상위 결과와 집계만 대화로 가져온다. 공유·동시 편집이 많으면 Google Sheets, 단일 컴퓨터 중심이면 로컬 Excel을 유지한다.
별도 데이터베이스 저장 방식은 이 스킬의 선택지로 확장하지 않는다.
